Detailed Description

template<typename T>
struct microla::fusion::SensorCalibration< T >

Runtime calibration for one entity's sensor package.

These values are device-specific and therefore intentionally runtime-configurable, while the gating and algorithm-policy knobs remain compile-time constants.
