Detailed Description

Generic matrix class Mat<T,R,C> with full operator support.

This header provides the template-based matrix class with comprehensive operator support, SIMD optimizations (CMSIS-DSP, NEON, MVE), and specialized functionality for embedded systems and real-time applications.
