inlinenoexcept

Construct a non-owning view into parent linear storage.

Parameters
dataPointer to the parent buffer containing elements.
parent_sizeNumber of elements in the parent buffer.
start_indexIndex of the first element in the parent buffer to include in the view.
strideStep between successive elements in the view (default: 1).
Note
The view does not take ownership of data. The caller must ensure that the parent storage outlives this view. When MICROLA_DEBUG is defined, runtime bounds checks are performed.
