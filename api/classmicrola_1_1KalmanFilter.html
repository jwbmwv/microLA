Detailed Description

template<typename T = float, std::size_t StateDim = 2, std::size_t MeasDim = 1>
class microla::KalmanFilter< T, StateDim, MeasDim >

Standard Kalman filter for linear systems.

Template Parameters
TNumeric type (typically float or double)
STATE_DIMNumber of state variables
MEAS_DIMNumber of measurements

Implements the optimal recursive estimator for linear Gaussian systems. Uses Joseph form covariance update for numerical stability. All dimensions known at compile time for zero-overhead abstractions.

template<typename T = float, std::size_t StateDim = 2, std::size_t MeasDim = 1>
auto microla::KalmanFilter< T, StateDim, MeasDim >::update ( const MeasVec &  z) -> bool
inlinenoexcept

Update step (measurement update) with innovation validation.

Parameters
zMeasurement vector
Returns
True if update was applied, false if measurement rejected

Incorporates measurement to refine state estimate: yₖ = z - H * x̂ₖ|ₖ₋₁ (innovation) Sₖ = H * Pₖ|ₖ₋₁ * H^T + R (innovation covariance) Kₖ = Pₖ|ₖ₋₁ * H^T * Sₖ⁻¹ (Kalman gain) x̂ₖ|ₖ = x̂ₖ|ₖ₋₁ + Kₖ * yₖ Pₖ|ₖ = (I - Kₖ * H) * Pₖ|ₖ₋₁ * (I - Kₖ * H)^T + Kₖ * R * Kₖ^T (Joseph form)
