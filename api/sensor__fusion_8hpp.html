Detailed Description

Relative sensor-fusion utilities for angle estimation between two entities.

Provides embedded-friendly orientation estimators for accelerometer-only, 6-axis IMU, and 9-axis IMU entities, plus a relative-angle estimator that can report a selectable scalar output together with drift and quality metadata.
