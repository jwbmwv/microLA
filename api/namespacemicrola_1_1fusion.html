◆ timestamp_needs_reset()

template<typename T >
constexpr auto microla::fusion::timestamp_needs_reset ( T  timestamp_s) -> bool
constexprnoexcept

Returns true when a float timestamp is old enough to cause millisecond- precision loss (~4.7 hours at 1 ms resolution).

Single-precision floats have 24 mantissa bits, giving exact integer millisecond representation only up to 2^24 ms ≈ 16 777 s ≈ 4.7 hours. Once timestamp_s exceeds this threshold, consecutive samples that differ by 1 ms may produce dt = 0 inside the estimator, silently stalling the fusion loop. Call this predicate periodically and reset the timestamp origin (and call OrientationEstimator::reset()) when it returns true.

Parameters
timestamp_sCurrent timestamp in seconds (float or double).
Returns
true if a float timestamp is at or past the precision cliff.
